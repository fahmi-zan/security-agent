# Definition of Done - Feature

## Purpose

Criteria that a feature must meet before considered complete and releasable.

## DoD Items

### Specification

- [ ] PRD written
- [ ] Acceptance criteria defined
- [ ] Architecture documented
- [ ] API specified
- [ ] Test cases written
- [ ] Deployment notes written
- [ ] Rollback strategy defined
- [ ] Monitoring plan defined

### Implementation

- [ ] All tasks complete
- [ ] Code follows standards
- [ ] Tests pass
- [ ] Coverage meets minimum

### Review

- [ ] Architecture review passed
- [ ] Security review passed
- [ ] Code review passed
- [ ] QA review passed
- [ ] Documentation review passed
- [ ] All blocking findings fixed

### Release Readiness

- [ ] Quality gates passed
- [ ] Version bumped
- [ ] CHANGELOG updated
- [ ] Release notes written
- [ ] Rollback plan ready
- [ ] Stakeholders notified

### Post-Release

- [ ] Feature verified in production
- [ ] Monitoring active
- [ ] Metrics tracked
- [ ] Feedback collected
