# Definition of Done - Architecture

## Purpose

Criteria for accepted architecture artifacts.

## DoD Items

- [ ] All architecture documents created
- [ ] All major decisions have ADRs
- [ ] All diagrams valid Mermaid
- [ ] Technology stack documented with rationale
- [ ] Quality attributes specified
- [ ] Constraints documented
- [ ] Risks identified with mitigation
- [ ] Security considered
- [ ] Performance considered
- [ ] No contradictions with requirements
- [ ] Architecture review passed
- [ ] Consistent with standards
