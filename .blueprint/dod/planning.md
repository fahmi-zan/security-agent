# Definition of Done - Planning

## Purpose

Criteria for a completed, accepted plan.

## DoD Items

- [ ] Plan covers all requirements
- [ ] Work broken into phases
- [ ] Milestones have dates
- [ ] Every task has an owner
- [ ] Dependencies identified
- [ ] Critical path identified
- [ ] Risks documented with mitigation
- [ ] Resources allocated
- [ ] Estimates realistic
- [ ] Success metrics defined
- [ ] Validated with stakeholders
- [ ] Plan versioned
