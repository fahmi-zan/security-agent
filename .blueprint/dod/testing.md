# Definition of Done - Testing

## Purpose

Criteria that testing must meet before work considered complete.

## DoD Items

### Test Coverage

- [ ] All acceptance criteria tested
- [ ] Unit test coverage ≥ 80%
- [ ] Critical paths fully covered
- [ ] Edge cases covered
- [ ] Error paths tested

### Test Execution

- [ ] All unit tests pass
- [ ] All integration tests pass
- [ ] All E2E tests pass
- [ ] Regression suite passes
- [ ] No flaky tests

### Test Quality

- [ ] Tests deterministic
- [ ] Tests isolated
- [ ] Tests meaningful
- [ ] Test data managed
- [ ] Test documentation updated

### Defects

- [ ] All critical defects fixed
- [ ] All high defects fixed or accepted
- [ ] Defects documented
- [ ] Fixes verified

### Reporting

- [ ] Test report generated
- [ ] Quality metrics recorded
- [ ] Coverage report generated
- [ ] Stakeholders informed
