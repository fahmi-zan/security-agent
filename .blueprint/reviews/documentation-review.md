# Documentation Review Standards

## Purpose

Standards for reviewing documentation quality.

## Checklist

- [ ] YAML front matter complete
- [ ] All required sections present
- [ ] Information accurate
- [ ] Code examples work
- [ ] Commands correct
- [ ] URLs valid
- [ ] Clear language
- [ ] Logical structure
- [ ] Terminology consistent
- [ ] Cross-references valid
- [ ] No broken links
- [ ] No placeholders
- [ ] No duplication (uses references)
- [ ] Versioned and owned

## Approval

Approved when:
- No missing sections
- All links valid
- Examples verified
- Consistent terminology
- Ready for publication
