# Naming Conventions

## Purpose
Ensure readable, consistent, and predictable code structures.

## Rules
1. **Variables/Functions:** `camelCase`
2. **Classes/Types/Interfaces:** `PascalCase`
3. **Constants:** `UPPER_SNAKE_CASE`
4. **Files:** `kebab-case`

## Enforcement
- Enforced via Biome / ESLint / Prettier.
