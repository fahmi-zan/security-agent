# User Personas

## Primary
1. **Software Engineer:** Developer yang membangun dan maintain application. Kebutuhan: Security feedback langsung dari codebase.
2. **Senior Engineer / Tech Lead:** Bertanggung jawab terhadap architecture. Kebutuhan: Threat model, security review, remediation.
3. **Security Engineer:** Melakukan security assessment. Kebutuhan: Evidence, attack path, reproducible findings.

## Secondary
1. **DevOps / Platform Engineer:** CI/CD integration.
2. **Engineering Manager:** Security posture.
3. **QA Engineer:** Security regression.
