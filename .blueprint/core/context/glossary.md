# Glossary

- **Agent:** AI system executing tasks.
- **Finding:** A discovered vulnerability or misconfiguration.
- **Evidence:** Concrete proof of finding (e.g. stack trace, specific code block).
- **Remediation:** Actionable fix for finding.
- **Playbook:** Domain-specific set of rules (e.g. Auth Playbook).
