# Documentation Review Checklist

## Purpose

Validates documentation completeness, accuracy, clarity, and consistency.

## Front Matter

- [ ] YAML front matter present
- [ ] All required fields present
- [ ] Valid status value
- [ ] Valid version (SemVer)
- [ ] Valid last_updated date

## Completeness

- [ ] All required sections present
- [ ] All features documented
- [ ] All APIs documented
- [ ] All configuration documented

## Accuracy

- [ ] Information correct
- [ ] Code examples work
- [ ] Commands correct
- [ ] URLs valid
- [ ] Screenshots current

## Clarity

- [ ] Clear language
- [ ] Logical structure
- [ ] Good headings
- [ ] Terminology defined
- [ ] Examples included

## Consistency

- [ ] Consistent terminology
- [ ] Consistent formatting
- [ ] Consistent style
- [ ] Consistent structure

## Traceability

- [ ] Cross-references valid
- [ ] Related documents linked
- [ ] No broken links
- [ ] Version info present

## Quality

- [ ] No placeholders
- [ ] No TODO/TBD/FIXME
- [ ] No duplication (uses references)
- [ ] Easy to maintain

## Usage

Run after any documentation creation or update.
