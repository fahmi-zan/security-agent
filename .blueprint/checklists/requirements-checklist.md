# Requirements Review Checklist

## Purpose

Validates requirement quality, completeness, and traceability.

## Completeness

- [ ] All business goals covered
- [ ] All user needs captured
- [ ] No missing scenarios
- [ ] Edge cases considered

## Clarity

- [ ] Unambiguous wording
- [ ] Single interpretation
- [ ] No undefined terms
- [ ] Testable statements

## Traceability

- [ ] Each requirement links to business goal
- [ ] Each requirement links to feature
- [ ] No orphan requirements
- [ ] Unique requirement IDs

## Quality

- [ ] Atomic (one requirement each)
- [ ] No overlapping requirements
- [ ] No contradictory requirements
- [ ] Prioritized (MoSCoW)
- [ ] Acceptance criteria defined

## Constraints

- [ ] Technical constraints documented
- [ ] Business constraints documented
- [ ] Regulatory constraints documented
- [ ] Performance constraints documented

## Verification

- [ ] Requirements validated with stakeholders
- [ ] Requirements approved
- [ ] Requirements versioned
