# Planning Review Checklist

## Purpose

Validates that project plans are complete, realistic, and actionable.

## Business Alignment

- [ ] Plan aligned with business goals
- [ ] Plan aligned with product roadmap
- [ ] Success metrics defined
- [ ] Scope documented
- [ ] Out-of-scope items explicit

## Structure

- [ ] Work broken into phases
- [ ] Milestones have dates
- [ ] Tasks have owners
- [ ] Dependencies identified
- [ ] Critical path identified
- [ ] Effort estimated

## Risk

- [ ] Risks identified
- [ ] Risk severity assessed
- [ ] Mitigation strategies defined
- [ ] Contingency planned

## Resources

- [ ] Resources allocated
- [ ] Resource constraints documented
- [ ] Timeline realistic
- [ ] Budget accounted

## Quality

- [ ] Definition of Done defined per phase
- [ ] Quality gates scheduled
- [ ] Review checkpoints scheduled

## Usage

Run during planning phase and at each milestone review.
